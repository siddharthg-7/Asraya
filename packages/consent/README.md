# @pramana/consent

Non-custodial consent contract engine, trusted template rendering, and verifiable consent receipts.

## Status

`NOT STARTED` (Setup Phase Only)

## Key Tenets

1. **Consent is NOT a generic boolean**: It is an immutable, bounded, cryptographic contract.
2. **Template-Driven**: The citizen wallet renders consent prompts from canonical registry templates to prevent spoofed/misleading text.
3. **Receipt Generation**: Produces non-repudiable consent receipts signed by the citizen wallet holding the exact scope and purpose.
